Detailed Description

harness wraps pbar_reporter and adds per-test lifecycle hooks for a peer device connected via a dedicated serial port.

Use add() to register a peer_hook subclass keyed by test name. Before starting a test the peer serial buffer is flushed and before() is awaited; after the test after() is awaited and the buffer is flushed again.
